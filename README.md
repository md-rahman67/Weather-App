# Weather App

A simple and responsive Weather App built using **HTML, CSS, and JavaScript**.

The app uses the **Open-Meteo Geocoding API** to find the latitude and longitude of a location and then fetches the current weather data using the **Open-Meteo Weather API**.

## Features

- 🌍 Search weather by city/location
- 🌡️ Displays current temperature
- 💧 Displays humidity
- 💨 Displays wind speed
- 📍 Converts location name into latitude & longitude
- ⚡ Uses Axios for API requests
- 🔄 Fetches real-time weather data

## Technologies Used

- HTML
- CSS
- JavaScript
- Axios
- Open-Meteo API
